# Last Block

폐허가 된 작은 도시 블록을 낮 동안 탐색하고, 제한된 시야·소음·감염을 관리하며 밤의 탈출을 준비하는 실시간 탑뷰 분대 생존 웹게임입니다.

기존 게임의 이름, 코드, 그래픽, 음악, 텍스트, 맵을 복제하지 않은 독립 프로젝트입니다. 모든 임시 캐릭터와 월드 표현은 제한된 팔레트의 도형을 코드로 생성합니다.

## 핵심 게임 루프

1. 은신처에서 출발해 주택, 편의점, 창고, 골목을 탐색합니다.
2. 컨테이너와 바닥 물자에서 무기·치료제·제작 재료를 확보합니다.
3. 도시의 서로 다른 건물에 고립된 생존자 네 명을 구조하고 `Q` 명령으로 함께 전투합니다.
4. 차량 배터리, 연료, 엔진 부품을 모읍니다.
5. 해가 진 뒤 탈출 차량을 수리하고 45초 동안 방어합니다.
6. 체력이나 감염도가 한계에 도달하기 전에 탈출합니다.

한 판의 목표 시간은 약 15~20분입니다.

## 기술 구성

- Phaser 3: 월드, 카메라, 입력, 코드 생성형 캐릭터, 이펙트
- TypeScript: 전투, AI, 감염, 제작, 시야, 저장 등 게임 규칙
- Vite: 개발 서버와 production 번들
- Vitest: Phaser와 분리된 순수 규칙 회귀 테스트
- HTML/CSS: HUD, 인벤토리·제작, 동료 명령, 일시정지 UI
- localStorage: 버전이 지정된 브라우저 세이브

React나 대형 UI 프레임워크를 사용하지 않습니다.

## 실행

Node.js 22 이상을 권장합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 데스크톱 Chrome에서 엽니다.

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

## 조작법

| 입력 | 기능 |
| --- | --- |
| `WASD` | 연속 이동 |
| `Shift` | 달리기, 더 큰 소음 발생 |
| 마우스 | 조준 |
| 월드 위 마우스 휠 | 카메라 확대/축소 (`0.35×`~`2×`) |
| 주변 지도 위 마우스 휠 | 표시 범위 확대/축소 (`16×16`~`64×64` 타일) |
| 왼쪽 클릭 | 현재 무기로 공격 |
| `E` | 조사, 줍기, 문, 구조, 차량 수리 |
| `R` | 권총 재장전 |
| `F` | 손전등 켜기/끄기 |
| `Q` | 구조한 동료 전원에게 적용되는 명령 패널 |
| `1`~`5` | 퀵슬롯 사용 |
| `Tab` | 인벤토리·제작 패널 |
| `M` | 주변 지도 → 전체 지도 → 닫기 |
| `Esc` | 저장·일시정지 메뉴 |
| `F2` | 개발 빌드 성능 계측 오버레이 표시/숨김 |

인벤토리에서 무기를 장착하고 아이템을 원하는 퀵슬롯에 배정할 수 있습니다.

## 구현된 시스템

- 128×128 타일의 도로 우선 도시 맵과 24×24 픽셀 단위 표현
- 가로·세로 간선도로, 두 방향 대각선 도로, 도로 양옆의 회전 footprint 건물
- 작은 발밑 충돌 영역을 사용하는 부드러운 실시간 이동
- 머리 원형, 몸통 타원, 팔 원형으로 구성한 탑뷰 캐릭터
- 식칼, 야구방망이, 권총과 방향성 근접 판정·벽 차단 hitscan
- 일반 좀비와 질주자, 시각/청각 분리, 조사·추격·공격·수색 상태
- 걷기, 달리기, 문, 공격, 총성, 제작, 폭발의 데이터 기반 소음
- 20칸 중첩 인벤토리, 5개 퀵슬롯, 사용·버리기·배정
- 붕대, 횃불, 권총탄, 바리케이드, 화염병 제작
- 체력, 물기/할퀴기 감염 차이, 70% 감염 페널티, 약품
- 8분 낮, 2분 해질녘, 6분 밤, 2분 새벽의 게임 시계
- 낮 420px/2.20rad, 밤 78px/0.78rad의 단계 보간형 기본 부채꼴 시야와 야간 300px 손전등, 횃불, 화염
- 서로 다른 건물에 배치되는 구조 가능한 동료 4명과 따라오기·사수·위치 이동·집중 공격 명령
- 4개 편대 슬롯, 분산된 A* 갱신, 벽 회피와 거리 기반 따라잡기가 적용된 동료 이동
- 플레이어와 커서 사이를 추적하고 `0.35×`에서도 정확한 중심을 유지하는 단계식 pixel-art 카메라 zoom
- `M`으로 순환하는 192×192 주변 지도와 512×512 전체 도시 지도; 전체 지도도 실제 `Unknown`/`Explored`/`Visible` fog를 별도 Canvas layer로 표시
- fog와 무관한 구조 동료·local window와 실제 Visible fog cell을 모두 만족한 살아 있는 좀비 전술 마커
- 공통 WorldObjectRegistry/InteractionSystem과 검은색 1px 엔티티 외곽선, `E`로 선택된 단 하나의 대상만 표시하는 흰색 강조
- ESC 설정에서 별도 저장되는 개발자 모드, 재료를 소비하지 않는 제작과 전체 지도 생존자 위치 표시
- map seed 기반 80% 초기 개방 문, 파괴 가능한 문·바리케이드와 저장되는 체력
- 우회 비용과 파괴 비용을 비교하고 경로상의 문·바리케이드를 공격하는 좀비 AI
- 탈출 부품 3개, 야간 수리, 45초 방어, 승리·패배 결과
- 안전지대 복귀, 동료 구조, 부품 획득, 메뉴 저장과 불러오기
- 재사용되는 312개 픽셀 이펙트 primitive와 분산된 좀비 AI/경로 갱신

## 픽셀 감염형 전장의 안개

월드를 타일보다 작은 3×3 월드 픽셀 셀로 나누고 각 셀을 `Unknown`, `Explored`, `Visible`로 관리합니다.

- 플레이어와 광원에서 8옥탄 recursive shadowcasting으로 시야를 계산합니다.
- 벽, 차량, 닫힌 문은 LOS와 전파를 함께 차단합니다.
- 낮은 가구는 시야 비용만 높이고 완전히 차단하지 않습니다.
- 반경 가장자리는 시드 기반 deterministic hash로 일부 셀이 빠집니다.
- 같은 세이브 시드와 위치에서는 경계가 깜빡이지 않고 동일합니다.
- 손전등은 마우스 방향의 좁고 긴 부채꼴 조건을 추가합니다.
- 현재 보이는 셀만 개체를 표시하며, 과거 탐사지는 지형만 청회색으로 남깁니다.
- 입력이 바뀔 때만 시야를 갱신하고, 변경된 셀의 texture 영역만 업로드합니다.
- 낮에는 손전등 on/off가 fog나 배터리에 영향을 주지 않고, 해질녘·새벽에는 smoothstep으로 효과가 이어집니다.

## 프로젝트 구조

```text
src/
├─ config/       해상도, 밸런스, 조작 상수
├─ core/         시계, RNG, 이벤트, 세이브 자료형
├─ data/         맵, 아이템, 무기, 제작법, 좀비 정의
├─ entities/     플레이어, 좀비, 동료, 바닥 아이템
├─ rendering/    코드 생성 스프라이트, 맵, 안개, 파티클 풀
├─ scenes/       부트, 타이틀, 월드, 결과 Scene
├─ systems/      충돌, 전투, AI, 안개, 소음, 제작, 감염, 저장
├─ tests/        순수 게임 규칙 테스트
└─ ui/           DOM HUD와 패널
```

Phaser Scene은 입력·엔티티 수명·카메라·렌더 연결을 담당하고, 테스트 가능한 규칙은 `systems/`에 분리합니다.

## 테스트 범위

- 시야 생성, 미탐사 유지, 탐사 흔적, 벽/문, 결정적 경계, 손전등 부채꼴
- 제작 성공/실패, 재료 소모, 인벤토리 공간 부족 롤백
- 할퀴기/물기 감염 차이, 약품, 0~100 제한, 감염 게임 오버
- 소음 범위, 조사 상태, 시야 추격, 마지막 위치 수색
- 플레이어·인벤토리·탐사 안개·동료 4명 저장 복원, v4 단일 동료 migration과 손상 데이터 처리
- 단계별 방향성 시야, 전체 지도 fog, local marker, 설정 분리, registry와 단일 interaction target

## GitHub Pages

`main` 또는 공개가 승인된 기능 브랜치가 workflow 대상이면 `.github/workflows/deploy-pages.yml`이 타입 검사, 테스트, build 후 `dist/`를 Pages에 배포합니다.

저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 지정해야 합니다. Vite의 상대 경로 base를 사용하므로 프로젝트 저장소 경로에서도 에셋을 불러올 수 있습니다.

## 알려진 제한 사항과 확장 후보

- 임시 도형 캐릭터와 생성형 타일을 실제 PNG 스프라이트/타일셋으로 교체할 수 있습니다.
- 한 개의 절차 생성 도시 맵과 네 명의 동료만 제공됩니다.
- 모바일 터치 조작, 온라인 멀티플레이, 차량 직접 운전은 범위에 포함하지 않습니다.
- 향후 Tiled JSON 가져오기, 더 다양한 감염자, 음향 에셋, 접근성 옵션을 확장할 수 있습니다.
